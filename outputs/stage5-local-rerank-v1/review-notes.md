# 5단계 사람 검토 노트

이 문서는 재순위화 비교 결과를 나중에 사람이 재검토하기 위한 해석 기록이다. 원시 결과는 `retrieval_results.jsonl`, 표 형식 결과는 `retrieval_results.csv`, 자동 집계는 `retrieval_summary.json`에 있다.

## 한 문장 요약

BM25 재순위화는 관련 TC를 조금 더 회수했지만 Hybrid RRF가 만든 상단 순서를 약화시켰고, 후보를 50개로 늘려도 관련성 지표는 개선되지 않았다. 따라서 **재순위화 없음과 후보 20개를 유지**한다.

## 비교 해석

### 동일 후보 20개 비교

- 최초 후보 ID와 순서가 모든 사례에서 동일함을 확인했다.
- BM25 재순위화 후 Precision은 0.2600에서 0.2667로, Recall은 0.9600에서 0.9778로 상승했다.
- 반면 MRR은 0.9667에서 0.9133으로, nDCG는 0.9012에서 0.8904로 하락했다.
- 회수량을 우선하면 BM25 재순위화가 유리하고, 중요한 근거의 상단 배치를 우선하면 재순위화 없음이 유리하다.

### 후보 20개와 50개 비교

- 2개 사례에서 최종 Top-10 결과가 달라졌다.
- 관련성 지표는 사례별로 모두 같았다.
- 현재 라벨만으로는 후보 50개의 추가 가치를 확인할 수 없다.

## 사람이 확인할 질문

- [ ] BM25 재순위화로 새로 포함된 관련 TC가 생성에 더 중요한가?
- [ ] 재순위화로 아래로 내려간 고등급 TC가 실제 생성 품질에 중요한가?
- [ ] 후보 50개에서 바뀐 `DEV-BOUNDARY-001`, `DEV-CONCURRENT-001`의 미판정 결과가 실제로 관련 있는가?
- [ ] Recall 0.0178 증가가 MRR 0.0534 하락보다 중요한가?
- [ ] 별도 의미 재순위화 모델이 필요할 정도로 현재 실패 사례가 중요한가?
- [ ] BM25 단독 검색과 BM25 재순위화의 운영 복잡도 차이를 고려했는가?

## 확정하면 안 되는 주장

- 재순위화는 항상 성능을 낮춘다.
- 후보 50개는 모든 데이터에서 불필요하다.
- MRR과 nDCG의 작은 차이가 통계적으로 유의하다.
- 현재 라벨에 없는 TC는 무관하다.
- 검색 순서 개선이 자동으로 생성 품질 개선을 의미한다.
