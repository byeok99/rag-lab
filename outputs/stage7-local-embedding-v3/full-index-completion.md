# Stage 7 전체 TC 인덱스 생성 기록

기존 운영 인덱스를 변경하지 않고 전체 원본 TC를 별도 인덱스 버전으로 생성했다.

| 인덱스 버전 | 모델 | 차원 | 원본 TC 수 |
|---|---|---:|---:|
| `stage7-full-local-hash-v1` | `local-hash-v1` | 384 | 2,571 |
| `stage7-full-bge-m3-v1` | `BAAI/bge-m3` | 1,024 | 2,571 |

대상은 현재 SQLite 저장소의 활성 원본 TC 10개 프로젝트이며, 생성 TC는 포함하지 않았다. BGE-M3는 Apple Silicon MPS에서 실행했고 `.tc-rag/models` 캐시를 사용했다.

이 전체 인덱스는 검색 가능한 전체 코퍼스를 확보하기 위한 것이다. 정량 검색 지표는 사람이 검토한 평가셋에만 정답 라벨이 있으므로, 기존 Stage 7 지표는 개발 평가 프로젝트 208건과 15개 라벨 사례 기준으로 해석한다. 다른 프로젝트 TC에 대한 품질 우열은 라벨 없이 주장하지 않는다.
