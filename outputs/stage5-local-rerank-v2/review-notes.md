# 5단계 사람 검토 노트

이 문서는 수정된 v2 재순위화 비교 결과를 나중에 사람이 재검토하기 위한 기록이다. 원시 결과는 `retrieval_results.jsonl`, 표 형식 결과는 `retrieval_results.csv`, 자동 집계는 `retrieval_summary.json`에 있다.

## 한 문장 요약

BM25 재순위화는 관련 TC를 조금 더 회수했지만 Hybrid RRF의 상단 순서를 약화시켰고, 후보를 50개로 늘리면 오히려 지표가 낮아졌다. 따라서 **재순위화 없음과 후보 20개를 잠정 유지**한다.

## 실험이 공정했는지 확인한 내용

- RRF의 벡터·BM25 원천 검색 깊이를 모두 50으로 고정했다.
- 재순위화 없음과 BM25-Rerank-20은 동일한 후보 20개를 같은 순서로 받았다.
- 후보 20개는 후보 50개 최초 목록의 정확한 앞 20개였다.
- 따라서 재순위화 효과와 후보 풀 크기 효과를 분리해 해석할 수 있다.
- 수정 전 v1은 이 조건을 만족하지 않아 비채택했다.

## 결과 해석

- 재순위화 없음은 MRR 0.9667, nDCG 0.9031로 상단 정렬이 가장 좋았다.
- BM25-Rerank-20은 Precision 0.2733, Recall 0.9889로 관련 TC 회수가 가장 좋았다.
- BM25-Rerank-50은 후보 20보다 모든 평균 지표가 낮아 추가 후보가 도움이 되지 않았다.
- 어떤 설정이 더 좋은지는 “근거 누락 최소화”와 “중요 근거 상단 배치” 중 무엇을 우선하는지에 따라 달라진다.

## 사람이 확인할 질문

- [ ] Recall 0.0156 증가가 MRR 0.0534 하락보다 중요한가?
- [ ] BM25-Rerank-20에서 새로 포함된 관련 TC가 실제 생성에 필수적인가?
- [ ] 재순위화로 아래로 내려간 고등급 TC가 실제 생성 결과에 영향을 주는가?
- [ ] 후보 50개에서 바뀐 9개 사례의 미판정 TC가 실제로 관련 있는가?
- [ ] RRF 원천 깊이 20과 50을 별도 통제 비교해야 하는가?
- [ ] 별도 의미 재순위화 모델을 평가할 필요가 있는가?

## 확정하면 안 되는 주장

- 재순위화는 항상 성능을 낮춘다.
- 후보 50개는 모든 데이터에서 불필요하다.
- RRF 원천 깊이 50이 20보다 우수하다고 검증했다.
- 작은 평균 차이가 통계적으로 유의하다.
- 검색 순서 개선이 자동으로 생성 품질 개선을 의미한다.
