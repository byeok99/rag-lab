# 7단계 완료 기록: 임베딩 모델 비교

## 상태

**미실행(not-run)**

이번 단계에서는 실제 임베딩 모델 비교를 실행하지 않았다. 사용자가 OpenAI API 실험을 제외했고, 코드베이스에 `local-hash-v1` 외 별도 로컬 의미 임베딩 제공자가 없기 때문이다. OpenAI API 결과나 모의 비교 결과를 생성하지 않았다.

## 확인한 제공자

- 현재 사용 모델: `local-hash-v1` (`mock` 실행 모드, 384차원)
- 비교 후보: OpenAI 호환 `/embeddings` 제공자
- 기타 로컬 비교 모델: 현재 의존성과 코드에 없음

문서와 질의를 같은 모델로 임베딩하고 모델별 인덱스를 분리해야 하므로, 실제 비교를 하려면 비교 모델의 인증·접근 허가와 비용 정책이 먼저 필요하다.

## 고정 예정 조건

- E2, C1, Hybrid RRF-60, Q3, Top-K 10
- 재순위화 없음
- 프로젝트·버전 필터
- RRF 원천 깊이 50
- 컨텍스트 예산 4,000 토큰

## 실행 계획 dry-run

- 설정: [`evaluation_config.stage7-embedding-model-v1.json`](../../examples/evaluation_config.stage7-embedding-model-v1.json)
- 계획 검색: 32회(16개 사례 × baseline/비교 모델)
- 계획 생성: 96회로 표시되지만 생성은 실행하지 않음
- 예상 비용: `null` (가격 정보가 없어 추정하지 않음)
- 실제 외부 호출: 0회

## 미실행 사유와 재개 조건

- `local-hash-v1`과 비교할 승인된 로컬 의미 임베딩 모델이 없다.
- OpenAI API는 현재 실험 범위에서 제외됐다.
- 인증 정보가 있더라도 사용자가 API 비교를 다시 허용하기 전에는 실행하지 않는다.
- 비교 모델이 준비되면 baseline과 비교 모델 각각 별도 인덱스·모델명·차원·거리 계산을 기록하고 동일한 Q3 질의를 재사용한다.

## 현재 결론

임베딩 모델 비교에 따른 설정 변경은 **없음**이다. 6단계에서 선택한 Q3 후보는 local-hash 개발셋 결과로만 유지한다.
