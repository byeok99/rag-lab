# 5단계 완료 보고서: 재순위화 비교

> **비채택:** 후보 수와 RRF 원천 검색 깊이가 함께 변경된 설계 문제를 발견했다. 공식 5단계 결과는 `../stage5-local-rerank-v2/stage5-completion.md`를 사용한다.

사람 검토용 평이한 해석과 확인 질문은 [`review-notes.md`](review-notes.md)에 별도로 기록했다.

## 범위

- 개발 평가셋: `tta-26-01181-eval-reviewed-v1`
- 평가 사례: retrieval 16건 중 관련성 라벨이 있는 15건을 검색 지표에 사용
- 고정 조건: E2, C1, Hybrid RRF-60, Q1, Top-K 10, 프로젝트·버전 필터, 컨텍스트 예산 4,000토큰
- 비교 1: 동일 후보 20개에서 재순위화 없음 vs BM25 재순위화
- 비교 2: 동일 BM25 재순위화에서 후보 20개 vs 50개
- 임베딩: `local-hash-v1` (`mock`)
- 생성: 미실행

## 후보 목록 기록 보강

재순위화 전 후보 목록을 사후 검증할 수 있도록 실행 결과에 `candidate_record_ids`를 추가했다. 테스트를 먼저 추가해 기존 결과에 필드가 없어 실패하는 것을 확인한 뒤 구현했다.

- baseline과 BM25-Rerank-20의 최초 후보 20개가 16/16 사례에서 순서까지 동일했다.
- BM25-Rerank-50은 각 사례에서 후보 50개를 사용했다.
- 전체 35개 테스트가 통과했고 평가 관련 모듈 커버리지는 82%였다.

## 실행 무결성

- 총 48건(16개 사례 × 3개 설정), 오류 0건, 결과 부족 0건
- 방식별 동일한 16개 사례 집합 사용
- 원본 TC 단위 중복 결과 0건
- 모든 결과가 4,000토큰 예산 안에 포함됨
- 실제 API 및 Codex CLI 호출 없음
- 실행 상태는 모두 `mock`

## 검색 지표

사례별 지표의 평균과 모집단 표준편차다.

| 설정 | Precision@10 | Recall@10 | MRR@10 | nDCG@10 |
|---|---:|---:|---:|---:|
| 재순위화 없음, 후보 20 | 0.2600 ± 0.1356 | 0.9600 ± 0.1497 | **0.9667 ± 0.1247** | **0.9012 ± 0.1355** |
| BM25 재순위화, 후보 20 | **0.2667 ± 0.1247** | **0.9778 ± 0.0831** | 0.9133 ± 0.2276 | 0.8904 ± 0.1730 |
| BM25 재순위화, 후보 50 | **0.2667 ± 0.1247** | **0.9778 ± 0.0831** | 0.9133 ± 0.2276 | 0.8904 ± 0.1730 |

## 해석

동일 후보 20개를 BM25로 재순위화하면 Precision은 0.0067, Recall은 0.0178 상승했지만 MRR은 0.0534, nDCG는 0.0108 하락했다. 즉 관련 TC의 총 회수는 조금 늘었지만, 가장 중요한 관련 TC를 앞쪽에 두는 Hybrid RRF의 순서 일부를 잃었다.

BM25 재순위화는 16/16 사례의 최종 순서를 변경했다. 이 구현에서는 Hybrid 후보 안에 포함된 BM25 상위 문서를 다시 BM25 점수로 정렬하므로 결과가 4단계 BM25 검색과 같은 지표를 보였다.

후보를 20개에서 50개로 늘렸을 때 2개 사례의 최종 Top-10 구성 또는 순서는 달라졌지만 관련성 지표는 모든 사례에서 동일했다. 현재 라벨 기준으로 후보 50개의 추가 이득은 확인되지 않았다.

## 토큰 예산 적용 후 선택 컨텍스트

| 설정 | 평균 추정 토큰 | 최대 추정 토큰 |
|---|---:|---:|
| 재순위화 없음, 후보 20 | 1,116.7 | 1,439 |
| BM25 재순위화, 후보 20 | 1,126.2 | 1,572 |
| BM25 재순위화, 후보 50 | 1,126.7 | 1,572 |

모든 설정에서 실제 선택 TC는 10개이며 토큰 예산 절단은 없었다.

## 단계 선택

다음 단계 주 설정은 **재순위화 없음 + 후보 20개**를 유지한다.

- Hybrid RRF의 MRR과 nDCG 우위를 보존한다.
- BM25 재순위화의 Recall 증가는 작고 BM25 단독 검색과 사실상 같은 지표가 됐다.
- 후보 50개는 관련성 지표를 개선하지 않아 추가 검색·저장 비용을 정당화하지 못했다.
- Recall을 최우선으로 판단하는 경우 BM25 검색 또는 BM25-Rerank-20은 여전히 대안이다.

단일 종합 점수나 통계적 유의성을 근거로 확정한 선택은 아니다.

## 남은 한계

- 재순위화 방법은 별도 의미 모델이 아니라 현재 정규식 토큰 BM25다.
- 관련성 라벨은 전수 판정이 아니므로 후보 50개에서 바뀐 미판정 TC의 실제 가치는 사람 검토가 필요하다.
- 관련 근거 없음 사례에서도 Top-10을 반환하며 근거 부족 판정은 없다.
- local-hash 벡터를 사용하는 개발셋 결과이므로 실제 의미 임베딩에 일반화하지 않는다.
