# Stage 7 완료 보고서: 로컬 임베딩 모델 비교

## A. 목적과 가설

E2 입력, C1 TC 단위, Q3 구조화 질의, Top-K 10, 후보 20, RRF 후보 50/RRF K 60, 프로젝트·버전 필터를 고정하고 BM25와 Local Hash 및 BGE-M3를 비교한다. 가설은 BGE-M3가 Local Hash보다 의미적으로 관련된 TC의 순위를 개선할 수 있다는 것이다.

## B. 코드 변경

- `SentenceTransformerEmbedder`를 선택적 의존성으로 추가했다.
- 모델명, revision, 차원, device, batch size, 정규화, 최대 길이, 캐시 디렉터리를 설정할 수 있다.
- 모델 로딩 실패, 빈 입력, 차원 불일치, 비유한 벡터, 메모리·디바이스 오류를 성공으로 위장하지 않는다.
- Stage 7 M0~M4 설정과 지표에 Hit Rate, 임베딩 시간, 검색 시간을 추가했다.
- 기존 mock/OpenAI 제공자와 CLI 호환성을 유지했다.

## C. 실행 환경

- Python 3.11.6, macOS arm64
- `sentence-transformers 5.7.0`, `torch 2.14.1` 설치 완료
- 대상 모델: `BAAI/bge-m3`, 설정 차원 1024, device auto, CPU fallback 허용
- OpenAI API 호출: 없음
- 모델 캐시 업로드: 없음
- 원본 TC 업로드: 없음

## D. 통제 조건과 실행

- 개발 분할 20개 사례를 사용했고 관련 라벨이 있는 15개 사례만 정량 지표에 포함했다.
- 총 80개 작업을 실행했다(5개 설정 × 16개 사례). 관련 라벨이 없는 3개 사례는 무관으로 확정하지 않았다.
- M0/M1/M3은 명시적 로컬 mock(Hash) 또는 BM25 실행으로 완료했다.
- M2/M4는 `sentence-transformers` 설치 후 Hugging Face 모델 파일을 다운로드하려 했으나 호스트 이름 확인 실패로 16개씩 `not_run` 처리했다.

M0/M1/M3은 의미 신경 임베딩의 실제 성능이 아니다. BGE-M3는 실행되지 않았으므로 어느 모델이 우수한지 결론을 내리지 않는다. M3가 이번 라벨 기준으로 가장 높은 수치를 보였지만, 평가셋 크기와 라벨 범위가 제한적이며 Hash 기반 결과일 뿐이다.

## F. 실패·미실행과 한계

- Hugging Face `https://huggingface.co` DNS/네트워크 오류로 BGE-M3 가중치를 확보하지 못했다.
- 모델 패키지 설치 성공은 모델 실행 성공을 의미하지 않는다.
- 개발 분할 라벨 기준 결과이며 전체 요구사항 커버리지나 제품 동작 정확성을 증명하지 않는다.
- 실제 BGE-M3의 메모리, 저장 용량, 검색 지연시간은 아직 측정되지 않았다.
- 생성 품질 비교는 이번 단계 범위에 포함하지 않았다.

## G. 현재 선택 가능한 후보

실제 의미 모델 후보를 선택할 수 없다. 실행된 범위에서는 M3가 M0/M1보다 균형이 좋지만, 이를 BGE-M3 추천으로 해석해서는 안 된다.

## H. 다음 단계

모델 파일을 사전에 로컬 캐시에 배치한 뒤 동일한 v2 설정으로 M2/M4만 재개한다. 이후 모델별 인덱스 크기·임베딩 시간·질문별 순위 차이를 비교하고, 상위 검색 설정 2개를 대상으로 Codex CLI G0/G1 생성 품질 비교를 별도 수행한다.

상세 JSONL/CSV와 실행 환경 기록은 로컬 `outputs/stage7-local-embedding-v2/`에 저장되어 있다.
