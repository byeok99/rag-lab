원본 TC 208건의 파싱 상태:

- 사전조건 있음: 0건
- 입력 있음: 0건
- 수행 절차 있음: 208건

따라서 이번 데이터로는 E2 대비 사전조건·입력 추가 효과를 측정할 수 없다. E2와 E3의 동률은 검색 효과가 같다는 일반 결론이 아니라 입력 차이가 존재하지 않았기 때문이다.

## 해석 제한

이 결과는 `local-hash-v1`을 사용하는 현재 구현에서 임베딩 입력 구성을 비교한 것이다. 의미 임베딩 모델 전반에 일반화할 수 없고 제품 요구사항 전체 커버리지나 실제 제품 동작 정확성을 증명하지 않는다. 관련성 정답은 검토된 라벨 기준이며 미판정 TC를 자동으로 무관하다고 확정하지 않는다.

무근거 사례도 각 설정에서 Top-5를 반환했다. 검색 단계에는 근거 부족을 판정할 임계값이 없으므로, 근거 부족 표시와 관련 없는 TC를 이용한 억지 생성 여부는 이번 단계에서 평가할 수 없다. 후속 Codex G0/G1 생성 평가에서 별도로 확인한다.

시간 기록은 현재 전체 실행 시간만 신뢰할 수 있다. 문서 임베딩, 질의 임베딩, 순수 검색, 인덱스 저장 시간이 완전히 분리되지 않았고 설정별 최초 실행과 캐시 재사용 실행이 섞여 있으므로 이번 결과로 지연시간 우열을 판단하지 않는다.

OpenAI 임베딩 실험은 범위에서 제외했다. 이전 네트워크 실패 행은 별도 실패 실행으로 보존되며 이번 결과에 집계하지 않았다. Codex CLI는 검색 단계에 사용하지 않았고 이후 G0/G1 생성 비교에서만 사용한다.
