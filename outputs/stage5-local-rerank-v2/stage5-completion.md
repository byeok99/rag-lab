# 5단계 완료 보고서: 재순위화 비교

사람 검토용 평이한 해석과 확인 질문은 [`review-notes.md`](review-notes.md)에 별도로 기록했다.

## 범위

- 개발 평가셋: `tta-26-01181-eval-reviewed-v1`
- 평가 사례: retrieval 16건 중 관련성 라벨이 있는 15건을 검색 지표에 사용
- 고정 조건: E2, C1, Hybrid RRF-60, Q1, Top-K 10, 프로젝트·버전 필터, 컨텍스트 예산 4,000토큰
- RRF 원천 검색 깊이: 벡터·BM25 각각 50개로 고정(`rrf_candidate_k=50`)
- 비교 1: 동일 후보 20개에서 재순위화 없음 vs BM25 재순위화
- 비교 2: 동일 최초 RRF 순위에서 BM25 재순위화 후보 20개 vs 50개
- 임베딩: `local-hash-v1` (`mock`)
- 생성: 미실행

## 설계 수정과 실행 이력

최초 v1에서는 `candidate_k`가 RRF 원천 검색 깊이와 재순위화 후보 수를 동시에 바꿨다. 후보 수 효과를 격리할 수 없어 v1을 비채택 처리하고 삭제하지 않았다.

v2에서는 `rrf_candidate_k`를 별도 설정으로 추가해 원천 깊이를 50으로 고정했다. 실행 결과에 재순위화 전 `candidate_record_ids`를 기록했다.

- baseline과 BM25-Rerank-20 후보 목록은 16/16 사례에서 순서까지 동일했다.
- 후보 20개 목록은 16/16 사례에서 후보 50개 목록의 정확한 prefix였다.
- 전체 36개 테스트 통과, 평가 관련 모듈 커버리지 82%

Stage 4 Hybrid는 RRF 원천 깊이 20을 사용했지만 이번 baseline은 격리 비교를 위해 50을 사용했다. 따라서 두 단계의 baseline 수치를 동일 조건의 반복 결과로 간주하지 않는다.

## 실행 무결성

- 총 48건(16개 사례 × 3개 설정), 오류 0건, 결과 부족 0건
- 원본 TC 단위 중복 결과 0건
- 모든 결과가 4,000토큰 예산 안에 포함됨
- 실제 API 및 Codex CLI 호출 없음
- 실행 상태는 모두 `mock`

## 검색 지표

사례별 지표의 평균과 모집단 표준편차다.

| 설정 | Precision@10 | Recall@10 | MRR@10 | nDCG@10 |
|---|---:|---:|---:|---:|
| 재순위화 없음, 후보 20 | 0.2667 ± 0.1350 | 0.9733 ± 0.0998 | **0.9667 ± 0.1247** | **0.9031 ± 0.1300** |
| BM25 재순위화, 후보 20 | **0.2733 ± 0.1340** | **0.9889 ± 0.0416** | 0.9133 ± 0.2276 | 0.8962 ± 0.1640 |
| BM25 재순위화, 후보 50 | 0.2667 ± 0.1247 | 0.9778 ± 0.0831 | 0.9133 ± 0.2276 | 0.8904 ± 0.1730 |

## 해석

동일 후보 20개를 BM25로 재순위화하면 Precision은 0.0066, Recall은 0.0156 상승했지만 MRR은 0.0534, nDCG는 0.0069 하락했다. 관련 TC 회수는 조금 늘었지만 첫 관련 TC와 등급 높은 TC의 상단 순서는 약화됐다.

재순위화는 16/16 사례의 최종 순서를 변경했다. 후보를 20개에서 50개로 늘리면 9/16 사례의 최종 Top-10이 달라졌으나 모든 평균 지표가 낮아졌다. 현재 데이터에서는 넓어진 후보 풀의 높은 BM25 점수 문서가 기존의 더 유용한 Hybrid 후보를 밀어낸 것으로 볼 수 있다.

## 토큰 예산 적용 후 선택 컨텍스트

| 설정 | 평균 추정 토큰 | 최대 추정 토큰 |
|---|---:|---:|
| 재순위화 없음, 후보 20 | 1,111.4 | 1,439 |
| BM25 재순위화, 후보 20 | 1,118.5 | 1,549 |
| BM25 재순위화, 후보 50 | 1,126.7 | 1,572 |

모든 설정에서 선택 TC는 10개이며 토큰 예산 절단은 없었다.

## 단계 선택

다음 단계 주 설정은 **재순위화 없음, 최종 후보 20개, RRF 원천 깊이 50개**로 잠정 선택한다.

- Hybrid RRF의 MRR과 nDCG 우위를 보존한다.
- BM25-Rerank-20의 Recall 이득은 0.0156으로 작고 상단 순위 지표가 낮아졌다.
- 후보 50개 재순위화는 후보 20개보다 모든 평균 지표가 낮았다.
- Recall을 최우선으로 판단하면 BM25-Rerank-20이 타당한 대안이다.

RRF 원천 깊이 50은 이번 격리 실험을 위해 도입됐으며 Stage 4의 20과 직접 비교한 통제 실험은 아니다. 6단계에서 주 설정으로 사용할 때 이 차이를 명시한다.

## 남은 한계

- 재순위화 방법은 별도 의미 모델이 아니라 정규식 토큰 BM25다.
- 관련성 라벨은 전수 판정이 아니므로 후보 50에서 새로 포함된 미판정 TC의 실제 가치는 사람 검토가 필요하다.
- 관련 근거 없음 사례에서도 Top-10을 반환하며 근거 부족 판정은 없다.
- local-hash 개발셋 결과이므로 실제 의미 임베딩에 일반화하지 않는다.
