# 6단계 완료 보고서: 실패 사례 기반 검색 조건 비교

사람 검토용 평이한 해석과 확인 질문은 [`review-notes.md`](review-notes.md)에 별도로 기록했다.

## 범위

- 개발 평가셋: `tta-26-01181-eval-reviewed-v1`
- 평가 사례: retrieval 16건 중 관련성 라벨이 있는 15건을 지표에 사용
- 고정 조건: E2, Hybrid RRF-60, RRF 원천 깊이 50, Top-K 10, 후보 20, 재순위화 없음, 프로젝트·버전 필터, 컨텍스트 예산 4,000토큰
- 비교 변수: Q2, Q3, MMR(λ=0.7), C2 청크(2,000자/200자 overlap)
- 용어 표준화: 제품 용어 사전 부재로 미실행
- 임베딩: `local-hash-v1` (`mock`)
- 생성: 미실행

## 실행 무결성

- 원본 TC 단위 중복 결과 0건
- 모든 설정에서 최종 10개 결과와 4,000토큰 예산을 사용

- 실행 상태는 모두 `mock`

## 실패 사례 중심 해석

- baseline이 일부 관련 TC를 놓친 `DEV-REBUILD-001`을 Q2와 Q3가 회수했다.
- Q2와 Q3는 모든 라벨 사례에서 Recall 1.0을 기록했다. Q3는 nDCG가 Q2보다 0.0106 높아 구조화된 상태·입력 정보가 상단 정렬에도 도움을 준 후보로 보인다.
- MMR은 다양성을 높이는 대신 관련 TC 회수를 크게 낮췄다. 15개 중 13개 사례에서 baseline보다 Recall이 낮아 현재 local-hash·RRF 조건에서는 채택하지 않는다.
- C2는 최종 원본 TC 순위와 지표가 baseline과 동일했다. 현재 데이터와 2,000자 기준에서는 청킹 이득을 확인하지 못했다.
- 토큰 평균은 baseline 1,111.4, Q2 1,115.4, Q3 1,118.2, MMR 1,127.8, C2 1,111.4로 모두 예산 안에 있었다.

## 단계 선택

7단계 이후의 질의 구성 주 설정은 **Q3 구조화 질의**로 잠정 선택한다.

- Q1 대비 Recall이 0.0267 상승했고 모든 라벨 사례에서 관련 TC를 포함했다.
- Q2와 Recall은 같지만 Q3의 nDCG가 0.0106 높았다.
- MMR은 현재 구현·임베딩에서 실패했으므로 보류한다.
- C2는 긴 TC가 실제로 청크 경계를 넘는 데이터가 충분하지 않아 효과를 판단하지 못했다.

Q3 선택은 현재 local-hash 개발셋의 후보 선택이며, 실제 의미 임베딩과 생성 품질에서 재검증해야 한다.

## 미실행 및 한계

- 용어 표준화는 사람이 승인한 제품 용어 사전이 없어 실행하지 않았다.
- 기능 대/중분류 필터는 사례의 구조화 질의에 분류 필드가 없어 실행하지 않았다.
- MMR의 낮은 결과는 다양성 자체의 일반적 실패가 아니라 현재 local-hash 벡터와 RRF 점수 조합의 결과일 수 있다.
- C2는 청크 단위 검색 후 원본 TC 복원은 검증했지만, 긴 TC가 충분한 데이터셋에서의 효과는 미실행이다.
- 관련 근거 없음 사례는 여전히 Top-10을 반환하며 근거 부족 판정은 없다.
