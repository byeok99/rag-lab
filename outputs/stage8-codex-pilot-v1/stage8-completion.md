# Stage 8 완료 보고서: Codex CLI G0/G1 초기 생성 비교

## 실험 조건

- 검색 근거는 `stage7-vector-db-v1`의 저장 Vector DB 검색 결과를 재사용했다.
- 비교 검색 설정: M0 BM25, M2 BGE-M3 Vector DB, M4 BGE-M3 Hybrid DB
- G0: 검색 근거 없음
- G1: 해당 검색 설정의 실제 검색 결과 제공
- G2: 제외
- Codex CLI `0.154.0`, 새 실행, 조건별 1회 반복
- 대표 개발 사례 3개: 정상, 경계값, 입력 오류
- 총 18회 실제 실행

## 자동 평가 결과

| 검색 설정 | 조건 | 실행 수 | 평균 후보 수 | 평균 유효 후보 비율 | 근거 없는 추론 문자열 | 근거 없음 자제 |
|---|---|---:|---:|---:|---:|---:|
| M0 BM25 | G0 | 3 | 0.00 | 0.000 | 0 | 3/3 |
| M0 BM25 | G1 | 3 | 0.67 | 0.667 | 0 | - |
| M2 BGE-M3 Vector | G0 | 3 | 0.00 | 0.000 | 0 | 3/3 |
| M2 BGE-M3 Vector | G1 | 3 | 1.00 | 1.000 | 0 | - |
| M4 BGE-M3 Hybrid | G0 | 3 | 0.00 | 0.000 | 0 | 3/3 |
| M4 BGE-M3 Hybrid | G1 | 3 | 0.67 | 0.667 | 0 | - |

G0는 세 검색 설정 모두 근거 없이 후보를 억지로 만들지 않았다. 이번 소표본에서는 BGE-M3 Vector G1의 자동 스키마·유효성 결과가 가장 안정적이었다. BM25와 BGE-M3 Hybrid의 G1 결과 일부는 추가 사람 검토가 필요하다.

자동 평가는 스키마, 근거 ID, 금지 문자열, 근거 없음 자제만 검사한다. 근거가 실제 주장을 충분히 뒷받침하는지, 실행 가능성, 판정 가능성, 신규 가치, 중복은 사람 평가가 필요하다.

## 실행 범위와 미실행

전체 개발 사례 16개 × 3회 반복의 288회 계획은 dry-run으로 확인했다. 초기 점검 원칙에 따라 대표 사례 3개 × 1회 반복 18회만 실제 실행했다. 전체 반복 실행은 아직 미실행이며, 이번 파일의 수치는 최종 품질 순위가 아니다.

OpenAI API는 호출하지 않았고 Codex CLI만 사용했다. Codex 도구 호출 이벤트는 CLI 출력에서 확인할 수 없어 `tool_calls_observed=null`로 기록했다.
