# 7단계 사람 검토 노트

## 검토 대상

이번 단계는 실행 결과가 아니라 임베딩 모델 비교의 실행 가능성 검토다.

## 사람이 확인할 질문

- [ ] OpenAI API 비교를 실험 범위에 다시 포함할 것인가?
- [ ] 사용할 비교 임베딩 모델과 버전을 승인했는가?
- [ ] 한국어와 영어 약어가 섞인 TC에 적절한가?
- [ ] 모델별 인덱스가 섞이지 않도록 별도 버전을 사용할 것인가?
- [ ] 모델별 비용과 호출 제한을 기록할 수 있는가?
- [ ] 비교 모델을 실제로 실행하기 전 dry-run과 비용 확인을 완료했는가?

## 확정하면 안 되는 주장

- local-hash가 의미 임베딩보다 우수하거나 열등하다.
- 임베딩 모델 비교 결과가 이미 존재한다.
- API 인증 정보가 있다는 이유만으로 실행이 승인됐다.
