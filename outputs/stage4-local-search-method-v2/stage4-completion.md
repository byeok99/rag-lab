# 4단계 완료 보고서: 검색 방식 비교

사람 검토용 평이한 해석과 확인 질문은 [`review-notes.md`](review-notes.md)에 별도로 기록했다.

## 범위

- 개발 평가셋: `tta-26-01181-eval-reviewed-v1`
- 평가 사례: retrieval 16건 중 관련성 라벨이 있는 15건을 검색 지표에 사용
- 고정 조건: E2, C1, Q1, Top-K 10, 후보 20개, 프로젝트·버전 필터, 재순위화 없음, 컨텍스트 예산 4,000 토큰
- 비교 방식: local-hash 벡터, 키워드 BM25, RRF 하이브리드(`rrf_k=60`)
- 생성: 미실행

키워드 검색은 한국어 형태소 분석기가 아닌 정규식 토큰(`[0-9A-Za-z_가-힣]+`) 기반 BM25다. 벡터는 `local-hash-v1` 모의 임베딩이므로 결과를 일반적인 의미 검색 성능으로 해석하지 않는다.

## RRF 수정 및 실행 이력

최초 v1 실행 후 BM25 점수가 0인 문서까지 RRF 순위에 포함되는 문제를 발견했다. 이 경우 DB 저장 순서가 하이브리드 점수에 영향을 줄 수 있었다.

- 회귀 테스트를 먼저 추가하고 실패를 확인했다.
- 각 검색기의 상위 `candidate_k=20`만 결합하도록 수정했다.
- BM25 점수가 0인 문서는 키워드 후보에서 제외했다.
- 수정 후 전체 34개 테스트가 통과했고 평가 관련 모듈 커버리지는 81%였다.
- v1 결과는 이력 보존을 위해 남겼지만 `NOT_SELECTED.md`로 비채택 표시했다.
- 아래 결과는 수정 후 새 실험 ID로 실행한 v2 결과다.

## 실행 무결성

- 총 48건(16개 사례 × 3개 방식), 오류 0건, 결과 부족 0건
- 방식별 16건의 동일 사례 집합 사용
- 점수 유형은 각각 `cosine_similarity`, `bm25`, `rrf`로 분리 기록
- 원본 TC 단위 중복 결과 0건
- 모든 실행은 `mock`으로 기록됐으며 API와 Codex CLI 호출은 없다.
- 모든 검색 결과가 4,000 토큰 예산 안에 들어가 컨텍스트 절단이 없었다.

## 검색 지표

사례별 지표의 평균과 모집단 표준편차다. 관련성 라벨이 있는 15건만 포함한다.

| 검색 방식 | Precision@10 | Recall@10 | MRR@10 | nDCG@10 |
|---|---:|---:|---:|---:|
| local-hash 벡터 | 0.2467 ± 0.1204 | 0.9267 ± 0.1670 | 0.7722 ± 0.2862 | 0.7850 ± 0.2495 |
| BM25 | **0.2667 ± 0.1247** | **0.9778 ± 0.0831** | 0.9133 ± 0.2276 | 0.8904 ± 0.1730 |
| Hybrid RRF-60 | 0.2600 ± 0.1356 | 0.9600 ± 0.1497 | **0.9667 ± 0.1247** | **0.9012 ± 0.1355** |

BM25는 Precision과 Recall이 가장 높았다. 하이브리드는 첫 관련 TC의 순위와 등급별 전체 정렬을 나타내는 MRR과 nDCG가 가장 높았다. 단일 종합 점수는 계산하지 않았다.

## 토큰 예산 적용 후 선택 컨텍스트

| 검색 방식 | 평균 전달 TC 수 | 평균 추정 토큰 | 최대 추정 토큰 | 관련 TC가 하나 이상 포함된 사례 |
|---|---:|---:|---:|---:|
| local-hash 벡터 | 10 | 1,124.9 | 1,388 | 15/15 |
| BM25 | 10 | 1,127.5 | 1,572 | 15/15 |
| Hybrid RRF-60 | 10 | 1,116.7 | 1,439 | 15/15 |

Recall이 1보다 낮은 사례는 벡터 3건, BM25 1건, 하이브리드 1건이었다. BM25와 하이브리드의 실패 사례는 서로 달라 검색 방식의 상호 보완 가능성이 남아 있다.

## 단계 선택

5단계 재순위화 비교의 주 설정은 **Hybrid RRF-60**으로 선택하고 **BM25를 대안 설정으로 보존**한다.

- 하이브리드는 MRR 0.9667, nDCG 0.9012로 근거 순서가 가장 좋았다.
- BM25보다 Recall은 0.0178 낮지만 모든 사례에 최소 하나의 관련 근거가 포함됐다.
- 생성 모델이 앞쪽 근거의 영향을 받을 수 있다는 선택 휴리스틱에 따라 하이브리드의 정렬 품질을 우선한다. 이 영향 자체는 아직 생성 실험으로 검증하지 않았다.
- BM25는 Recall 0.9778로 가장 높고 임베딩 호출이 필요 없으므로 비용·단순성 대안이다.

이 선택은 local-hash 개발셋의 단계 후보다. 이후 실제 의미 임베딩 모델을 비교하면 다시 검증해야 한다.

## 남은 한계

- 관련 근거 없음 사례에서도 각 방식은 10개를 반환했다. 근거 부족 판정은 아직 없다.
- 관련성 라벨은 전수 판정이 아니므로 미판정 결과를 자동으로 무관하다고 확정하지 않는다.
- 현재 키워드 토큰화는 조사·활용형을 분리하지 않아 한국어 검색에 한계가 있다.
- 벡터와 하이브리드가 동일 E2 문서 벡터를 별도 실험 인덱스로 저장하는 중복은 성능에 영향을 주지 않지만 저장 비효율이다.
- API 직접 호출과 G2는 제외한다. 생성 비교는 나중에 Codex CLI G0/G1만 수행한다.
